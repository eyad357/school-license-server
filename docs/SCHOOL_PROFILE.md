# بيانات المدرسة: المدينة ونوع المدرسة والمرحلة الدراسية (migration 008)

## ما الذي أُضيف
- على سجل العميل/الترخيص (`customers`): `city` (نص)، `school_type_id`، `school_stage_id` — كلها **اختيارية**.
- قائمتان **منفصلتان** تُدارانِ من لوحة الإدارة (تبويب «قوائم المدرسة»):
  - أنواع المدارس (`school_types`): حكومي، أهلي، رياض الأطفال، تربية خاصة.
  - المراحل الدراسية (`school_stages`): رياض الأطفال، ابتدائي، متوسط، ثانوي، تربية خاصة.
- السجل يرتبط بالخيار بمعرّفه الرقمي، فتعديل الاسم لا يكسر الربط.

## تطبيق الـ migration بأمان
```
node scripts/migrate.js --plan  src/db/008_school_profile.sql   # تجربة تُلغى تلقائيًا
node scripts/migrate.js --apply src/db/008_school_profile.sql
```
- إضافي فقط (لا حذف ولا تعديل لبيانات موجودة)، ويعمل داخل معاملة واحدة، ويمكن تشغيله أكثر من مرة.
- القيم الافتراضية تُدخَل **عند إنشاء الجدول فقط**؛ إعادة التشغيل لا تعيدها ولا تلغي تعديلاتك.
- طبّقه **قبل** نشر كود هذه النسخة (الكود الجديد يستعلم عن الجداول الجديدة).
- الرجوع بالكود لا يحتاج أي تراجع في قاعدة البيانات (الكود القديم يتجاهل الأعمدة الجديدة).

## واجهات API (كلها تتطلب توكن الأدمن)
| الطريقة | المسار | الوصف |
|---|---|---|
| GET | `/api/v1/admin/school-options` | القائمتان معًا (مع الحالة وعدد السجلات المستخدمة) |
| GET/POST | `/api/v1/admin/school-types` ، `/school-stages` | عرض / إضافة `{name}` |
| PATCH | `.../school-types/:id` ، `.../school-stages/:id` | `{name?, isActive?, confirm?}` — تغيير اسم خيار مستخدم يتطلب `confirm:true` |
| DELETE | `.../school-types/:id` ، `.../school-stages/:id` | يُرفض (409 `in_use`) إن كان الخيار مستخدمًا؛ عطّله بدل حذفه |
| PATCH | `/customers/:ref` | حقول جديدة اختيارية: `city`, `schoolTypeId`, `schoolStageId` (`null`/`''` للمسح) |
| POST | `/licenses/:id/assign-customer` | يقبل نفس الحقول |
| GET | `/license-records` | يعيد `city`, `school_type_name`, `school_stage_name` + فلاتر `city`, `schoolTypeId`, `schoolStageId` (`none` = بدون) |
| GET | `/records/import-template[?prefill=incomplete]` | قالب Excel بقوائم منسدلة تتبع الإعدادات الحالية |
| POST | `/records/import[?dryRun=1][&clearEmpty=1]` | رفع ملف xlsx خام (`Content-Type: application/octet-stream`) |

الطلبات القديمة التي لا ترسل الحقول الجديدة تعمل كما كانت ولا تغيّر القيم المحفوظة.

## Excel
- **التصدير:** الأعمدة الـ14 القديمة كما هي وبنفس ترتيبها، ثم `المدينة`، `نوع المدرسة`، `المرحلة الدراسية` في آخر الجدول.
- **القالب:** ورقة `التراخيص` (الأعمدة: رقم العميل، مفتاح التفعيل، اسم العميل، الهاتف، المدينة، نوع المدرسة، المرحلة الدراسية، السعر الفعلي، العملة، تاريخ البيع، الملاحظات) + ورقة `القوائم` + ورقة `تعليمات`.
- **الاستيراد يحدّث سجلات موجودة فقط** (بـ«رقم العميل» أو «مفتاح التفعيل»)؛ لا ينشئ مفاتيح ولا يغيّر الترخيص أو الأجهزة، ولا يضيف خيارات جديدة للقوائم.
  - كل شيء أو لا شيء: أي خطأ ⇒ لا يُحفظ أي صف، ويُعاد الصف والعمود والسبب (HTTP 422).
  - عمود غير موجود في الملف ⇒ لا يتغير الحقل. عمود موجود وخليته فارغة ⇒ لا يتغير الحقل أيضًا، إلا مع `clearEmpty=1`.
  - الأعمدة غير المستخدمة (مثل «البرنامج» في ملف مُصدَّر) تُتجاهل ويُعاد اسمها في `ignoredColumns`.
  - الحد الأقصى: 5 ميغابايت و5000 صف. صيغة xlsx فقط.
