# متغيرات البيئة

استُخرجت من الكود الفعلي (`grep process.env`). **لا تضع القيم الحقيقية في أي ملف داخل المستودع.** مكانها: Railway → Variables.

| المتغير | مطلوب؟ | الوصف |
|---|---|---|
| `DATABASE_URL` | نعم | رابط PostgreSQL. في Railway يُمرَّر من خدمة قاعدة البيانات. **خدمة الاختبار يجب أن تشير إلى قاعدة اختبار منفصلة.** |
| `ALLOW_LOCAL_DATABASE` | لا | في الإنتاج (`NODE_ENV=production` أو متغيرات Railway) يرفض التطبيق البدء إذا كان `DATABASE_URL` غائبًا/فارغًا أو يشير إلى localhost، بدل الرجوع بصمت إلى `localhost:5432`. اضبطه `1` فقط إذا كانت قاعدة محلية مقصودة. |
| `JWT_SECRET` | نعم | سرّ توقيع جلسات الإدارة. نص عشوائي طويل. تغييره يُنهي كل جلسات الإدارة الحالية (لا يؤثر على العملاء). |
| `ADMIN_USERNAME` | نعم | اسم مستخدم لوحة الإدارة. |
| `ADMIN_PASSWORD_HASH` | نعم | bcrypt hash لكلمة المرور (وليس كلمة المرور نفسها). |
| `PORT` | لا | Railway يحدده تلقائيًا. الافتراضي 3100. |
| `API_RATE_LIMIT_MAX` | لا (**جديد**) | حد الطلبات في الدقيقة لكل IP على `/api/`. الافتراضي 100 = نفس السلوك السابق. |
| `PADDLE_API_KEY`, `PADDLE_WEBHOOK_SECRET`, `PADDLE_PRICE_ID` | فقط إن فعّلت الدفع | مسار الدفع الحالي (لم يُعدَّل). |
| `PADDLE_API_BASE_URL` | لا | الافتراضي `https://api.paddle.com`. |
| `MYFATOORAH_API_KEY`, `MYFATOORAH_WEBHOOK_SECRET`, `MYFATOORAH_BASE_URL` | لا | ملف قديم ما زال في الكود؛ الدفع الحالي عبر Paddle. |

## متغيرات الاختبار فقط (جهازك المحلي، ليس Railway)

| المتغير | الوصف |
|---|---|
| `TEST_DATABASE_URL` | قاعدة اختبار **محلية** يحتوي اسمها على كلمة `test`. الاختبارات **تحذف وتعيد بناء** مخطط `public` فيها. ترفض الاختبارات العمل إذا كان المضيف غير محلي أو الاسم لا يحتوي `test`. |
| `ALLOW_REMOTE_TEST_DB=1` | يسمح بمضيف غير محلي. لا تستخدمه إلا مع قاعدة اختبار مؤقتة بالكامل، **وليس أبدًا** مع قاعدة الإنتاج. |

## توقيع التراخيص (اختياري — جديد)

| المتغير | الوصف |
|---|---|
| `LICENSE_SIGNING_PRIVATE_KEY` | المفتاح **الخاص** Ed25519 بصيغة PEM (يُسمح بكتابة الأسطر الجديدة كـ `\n`). **سرّ**: لا يوضع في Git ولا في ZIP ولا في برنامج Windows. إن لم يُضبط فلا يُضاف أي حقل `signedLicense` والاستجابات كما كانت تمامًا. مفتاح غير صالح يعطّل التوقيع فقط ولا يكسر التفعيل. |
| `LICENSE_SIGNING_KEY_ID` | معرّف المفتاح (الافتراضي `k1`). يجب أن يطابق مفتاح `publicKeys.js` في برنامج Windows. |

## متغيرات المرحلة H (جديدة، كلها اختيارية بقيم افتراضية آمنة)

| المتغير | الافتراضي | الوصف |
|---|---|---|
| `LICENSE_EVENTS_HEARTBEAT_MS` | 25000 | نبضة البث |
| `LICENSE_EVENTS_MAX_AGE_MS` | 1800000 | عمر الاتصال قبل إعادة التدوير |
| `LICENSE_EVENTS_POLL_MS` | 5000 | استطلاع احتياطي إن سقط LISTEN |
| `LICENSE_EVENTS_MAX_CONNECTIONS` | 5000 | سقف اتصالات البث لكل نسخة |
| `LICENSE_EVENTS_REPLAY_LIMIT` | 50 | أقصى أحداث تُعاد قبل `resync` |
| `LICENSE_EVENTS_RETENTION_DAYS` | 30 | مدة الاحتفاظ بالأحداث للإعادة |
| `LICENSE_EVENTS_RETRY_MS` | 30000 | `retry:` المُرسل للعميل |
| `DB_POOL_MAX` / `DB_CONNECT_TIMEOUT_MS` | 20 / 10000 | حجم pool ومهلة الاتصال |
| `LOGIN_RATE_LIMIT_MAX` | 10 | محاولات دخول فاشلة / 15 دقيقة / IP |

## TRUST_PROXY (جديد — أمني)

| المتغير | الافتراضي | الوصف |
|---|---|---|
| `TRUST_PROXY` | `1` (= السلوك السابق: وسيط عكسي واحد، أي حافة Railway) | عدد الوسطاء الموثوقين أمام الخدمة. `false` أو `0` إن كانت الخدمة تُستقبل مباشرة بلا وسيط (X-Forwarded-For يُتجاهل). رقم 2..5 لعدة وسطاء. أو قائمة عناوين/نطاقات مفصولة بفواصل. **`true` ونطاقات واسعة (`0.0.0.0/0`, IPv6 أقصر من /96) مرفوضة وتمنع تشغيل الخدمة.** يحدد `req.ip` الذي تعتمد عليه كل حدود المعدل بما فيها حد دخول الإدارة. |
