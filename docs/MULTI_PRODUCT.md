# إدارة عدة برامج من لوحة واحدة

## ما الذي كان موجودًا وأُعيد استخدامه
جدول `products` وعمود `licenses.product_id` (مفتاح أجنبي) **موجودان أصلًا** في المخطط، وعمليات `activate / validate / deactivate` تتحقق فعلًا من `product_id` (`WHERE license_key = $1 AND product_id = $2`). لذلك لم يُنشأ أي مفهوم مكرر؛ أُضيفت فقط إدارة هذه البيانات والتحقق من الاختيار.

## ما الذي أُضيف (الترحيل `005_products_platform.sql` — إضافي)
- `products.description` و`products.status` (`active` | `disabled`) و`products.updated_at`.
- حارس (Trigger) يمنع تغيير `products.product_id` بعد إنشائه، حتى لو جرّب أحد SQL مباشرًا.
- لا يغيّر أي بيانات موجودة؛ اسم برنامج المدرسة الحالي (`Accreditation Pro`) كما هو.

## سياسة الإدارة
| الإجراء | النتيجة |
|---|---|
| إضافة برنامج | `productId` (حروف إنجليزية صغيرة/أرقام/شرطات، 2–64) + اسم + وصف. المعرّف **ثابت** ولا يُحذف البرنامج أبدًا. |
| تعديل | الاسم والوصف والحالة فقط. محاولة تغيير المعرّف ترجع 400. |
| تعطيل برنامج | لا تراخيص جديدة له، ولا تفعيل **أجهزة جديدة**. الأجهزة المفعّلة تواصل العمل (لا يُقفل أي عميل بسبب التعطيل). التراخيص التي دفع عملاؤها فعلًا عبر Paddle تُصدر حتى لو عُطّل البرنامج. |
| إنشاء ترخيص | **اختيار البرنامج إلزامي** (لا افتراضي): الواجهة تبدأ بـ «— اختر البرنامج —» وتُصفَّر في كل مرة، والـAPI يرفض الطلب بلا `productId` أو ببرنامج غير موجود أو معطّل. |
| استخدام مفتاح برنامج A في B | يُرفض: `invalid`. العملاء القدامى الذين لا يرسلون `productId` يُعاملون كبرنامج المدرسة. |

## الاستخدام من اللوحة
1. تبويب «البرامج» ← «+ إضافة برنامج».
2. تبويب «التراخيص» ← «+ إنشاء تراخيص» ← اختر البرنامج.
3. قائمة تصفية «كل البرامج» وعمود «البرنامج» في الجدول؛ البحث يشمل اسم البرنامج؛ التصدير (CSV/Excel) فيه عمود «البرنامج» ويحترم الفلتر.
4. بطاقات الأعداد تتبع الفلتر؛ جدول البرامج يعرض لكل برنامج: التراخيص (والنشط منها) والعملاء والأجهزة.

## API (كلها تتطلب توكن الإدارة)
```
GET   /api/v1/admin/products
GET   /api/v1/admin/products/:productId
POST  /api/v1/admin/products           { productId, name, description? }
PATCH /api/v1/admin/products/:productId { name?, description?, status? }
POST  /api/v1/admin/licenses/bulk      { productId, quantity | customers, ... }   // productId إلزامي
POST  /api/v1/admin/licenses           { productId, customer, maxDevices, ... }   // productId إلزامي
GET   /api/v1/admin/license-records?productId=...
```

## إضافة برنامج Electron/آخر جديد
في عميله اجعل `PRODUCT_ID` (في `config.js`) يساوي نفس المعرّف، وأرسله في طلبات التفعيل/التحقق/الإلغاء. مفاتيح الترخيص تُصدر من اللوحة بعد اختيار البرنامج. (صيغة المفتاح ما زالت `SCHL-…` لكل البرامج؛ هذا شكلي فقط ولم أغيّره حفاظًا على التوافق.)
